## 🔄 Flux de Données

### **Flux Utilisateur Frontend**
```
User → CloudFront → S3 (React App) → API Gateway → Microservices
```

### **Flux Communication Inter-Services**
```
Order Service → Kafka → Payment Service → Email Service
              ↓
           Database → Redis Cache
```

### **Flux Monitoring**
```
Microservices → Prometheus → Grafana Dashboard
             ↓
         Zipkin Traces → Debugging Interface
             ↓
         Loki Logs → Search & Analysis
```

## 📊 Auto-Scaling Configuration

### **EKS Cluster Auto Scaler**
```yaml
Horizontal Pod Autoscaler (HPA):
  - Target CPU: 70%
  - Min Replicas: 2
  - Max Replicas: 10
  - Scale Up: +2 pods every 3 minutes
  - Scale Down: -1 pod every 5 minutes

Cluster Autoscaler (CA):
  - Min Nodes: 1 per AZ
  - Max Nodes: 5 per AZ
  - Scale Up: New node in 2-3 minutes
  - Scale Down: After 10 minutes idle
```
